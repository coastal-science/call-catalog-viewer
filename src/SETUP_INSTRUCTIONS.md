# Setup Instructions - Installing Python Dependencies

## Overview

This guide explains how to install the Python packages (dependencies) needed to run the scripts in this project.

All configuration files are in the `src/` folder:
- `src/pyproject.toml` - Project configuration and dependencies
- `src/.python-version` - Python version for pyenv
- `src/requirements.txt` - Original requirements (can be kept for reference)
- `src/requirements.lock` - Lock file (if using pip-compile)
- `src/uv.lock` - uv lock file (generated by `uv sync`)

## Installing Dependencies

From the project root directory, run these commands to install the required Python packages:

### Basic Commands

```bash
# Install/update all required packages
uv sync --directory src

# Run Python scripts (after installing dependencies)
uv run --directory src -- python src/add_catalog.py ...

# Example: Add a catalog
uv run --directory src -- python src/catalog_config.py add ...
```

### Environment Variables

You can set `UV_WORKING_DIR` to avoid typing `--directory src` every time:

```bash
export UV_WORKING_DIR=src
uv sync
uv run python src/add_catalog.py ...
```

### Creating Aliases (Recommended)

Add to your `~/.bashrc` or `~/.zshrc`:

```bash
# uv commands for call-catalog-viewer
alias uvsync='uv sync --directory src'
alias uvrun='uv run --directory src --'
alias uvinstall='uv pip install --directory src'
```

Then use:
```bash
uvsync                    # Sync dependencies
uvrun python src/add_catalog.py ...  # Run scripts
```

### CI/CD Usage

In GitHub Actions or other CI:

```yaml
- name: Install dependencies
  run: uv sync --directory src

- name: Run script
  run: uv run --directory src -- python src/add_catalog.py ...
```

### Docker Usage

```dockerfile
WORKDIR /app
COPY src/pyproject.toml src/.python-version src/
RUN uv sync --directory src
COPY src/ src/
RUN uv run --directory src -- python src/add_catalog.py ...
```

## Benefits

- ✅ Keeps all Python/uv config in `src/` folder
- ✅ Can run `uv` commands from project root
- ✅ Clean separation of concerns
- ✅ Works with existing project structure

## Notes

- The `.venv` will be created in `src/.venv/`
- Lock files (`uv.lock`) will be in `src/`
- All `uv` commands need `--directory src` flag (or use `UV_WORKING_DIR`)
